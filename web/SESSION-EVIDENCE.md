# Protected post-End metadata inspector

R5 source construction; runtime unverified. This inspector is separate from local approved-artifact replay/review. It never loads or plays audio, creates a session, mutates authority, polls, or follows returned references.

The browser captures session/run/trial/boot identity from its admitted ready envelope and metadata. The evidence target is that session only. A private launch nonce is used solely in the HTTP `X-Voicelab-Nonce` header for this feature; it is absent from diagnostics, DOM metadata, exports and storage. Start, clear, mode/arm/credential changes and pagehide revoke the inspection lease and abort pending reads. Admission-version checks prevent a delayed ready from restoring a revoked lease. Existing WebSocket admission transport is unchanged.

After local End or the owned relay's ended message and full session-owned handle cleanup, an operator can explicitly inspect/refresh. The request is same-origin POST `/sessions/{owned_id}/evidence`, exact two-byte `{}` body, JSON content type, browser-controlled Host/Origin, no credentials, cache, redirects, referrer or GET fallback. The browser and relay must share the exact loopback HTTP origin; the separate-origin development serving case is visibly incomplete and refused. D4's R5 alias routes to its canonical read-only GET projection after the same authentication. HTTP is not exercised in Dirty Mode. Final D4 freeze/source hashes are pending; generated bindings are deliberately unchanged.

Each read has a generation-owned AbortController, ten-second abort timeout, incremental eight-MiB response bound and strict UTF-8/JSON decoding. Only one pending read is allowed. Abort/cancel/reader lock/timer ownership remains counted until settlement. Diagnostics expose only request/controller/reader/timer counts under `session_evidence_handles`. No body, secret, URL, identity or evidence content is added to the browser trace API.

The closed display projection supports evidence schema version 1, requires matching root and session identities, and limits structure to depth 12 / 40,000 nodes and each list to 256 rows. Excess bytes/structure are rejected; list truncation is explicit. Missing, malformed and unsupported values are null/unknown. Source-indexed unresolved/foreign rows are not silently joined. Opaque fields, raw text/audio, task challenges, arguments, free reasons, headers and provider outputs are omitted. Fixed codes describe errors; error bodies are not displayed. This projection is not a second authoritative payload schema or custom-validator certification.

Display includes saved terminal/trace/artifact hash references, turns/epochs, task operation and duplicate-attempt metadata, exact saved-session attempt lineage, bounded calibration phase metadata and whole-run ledger summary. Received hash references do not verify artifact bytes. Whole-run snapshots replace previous views, are labeled as whole-run, and are never summed or attributed to the selected session. Reservation/settlement decimal strings remain strings. Unresolved lineage and unknown usage/exposure remain visible. HTTP session epochs absent from the producer remain null; last browser envelope epochs are a separately labeled observation. No cross-clock arithmetic is performed.

Licensed K generation zero is shown only with the producer's explicit licensed-fixed-PCM/no-provider-component declaration. Other costs stay unknown; `control_complete` remains descriptive. Spoken/task/confirmation correctness, physical sound, acoustic calibration and acceptance remain unknown. No independent reviewer/custodian or successful playback is asserted.

Deferred activation prerequisites: exact-origin serving, valid operator launch/admission, any required saved snapshots, final D4 bindings freeze and runtime verification when Dirty Mode closes. The broad canonical ServerMessage payload registry and calibration HTTP client remain separately owned/dispatched work, not fabricated by this inspector.
